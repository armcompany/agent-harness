# 04 — UX

41. PHASE 5 — UX ARCHITECTURE

Model critical journeys.

For each journey determine:

ENTRY
 ↓
USER ACTION
 ↓
SYSTEM RESPONSE
 ↓
SUCCESS
 ↓
FAILURE
 ↓
RECOVERY

Consider:

first run
empty states
loading
slow responses
errors
permissions
destructive actions
confirmation
retries
session expiration
navigation
offline behavior
degraded behavior

A beautiful interface with a broken workflow is a failed implementation.

⸻

42. GOLDEN PATH

Identify the most valuable user journey.

Example:

Acquire User
 ↓
Sign Up
 ↓
Onboarding
 ↓
First Value
 ↓
Core Action
 ↓
Successful Result
 ↓
Return / Retention

Prioritize implementation and E2E validation around the golden path.

⸻

71. ACCESSIBILITY

Review where relevant:

semantic HTML
keyboard navigation
focus states
labels
contrast
screen-reader semantics
touch target size
error messaging
reduced motion

Accessibility is product quality.

⸻

72. RESPONSIVE DESIGN

Do not assume desktop-only behavior unless explicitly required.

Validate relevant layouts across:

mobile
tablet
desktop
large desktop

Do not simply shrink desktop layouts.

Adapt hierarchy where necessary.

⸻
