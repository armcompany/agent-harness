# Quality Gates

| Gate | Evidence required | Status |
| --- | --- | --- |
| Build | Fresh successful build, or not applicable rationale | pending |
| Tests | Fresh relevant test results | pending |
| Runtime | Observable behavior in a representative environment | pending |
| Browser UI | Real browser validation when applicable | pending |
| Simplification | Unnecessary complexity reviewed and removed | pending |
| Production readiness | Risks, observability, rollback, and ownership assessed | pending |
